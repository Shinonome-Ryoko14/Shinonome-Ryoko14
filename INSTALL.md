# Install this GitHub profile

1. Create a **public** repository whose name exactly matches your GitHub username.
2. Copy `README.md` and the `assets/` directory into that repository.
3. Commit and push the files to the default branch.
4. Edit the README:
   - Replace `Shinonome-Ryoko14` if your actual username differs.
   - Verify every project link and remove any technology you do not want to claim.
   - Add other repositories only when you are ready to feature them.
5. The SVG banner is local, so it does not rely on an external image host.

## Notes
- The GitHub Stats and Top Languages cards use a public third-party endpoint and may be rate-limited or temporarily unavailable.
- The profile views badge is optional; remove it if you prefer not to display view counts.
- The banner uses SVG. GitHub supports SVG images in README files, but preview behavior can vary across clients. If it does not render in your context, export `assets/terminal-banner.svg` to PNG and reference that instead.
- This profile uses restrained motion only in the optional `terminal-divider.svg`; the main banner remains static to keep the page lightweight.
